# 龙娘背景素材生成说明

模式：内置 imagegen，编辑已有图片并保留透明背景。未使用 CLI 或 API 脚本。

输入角色：用户在本聊天提供的龙娘三视图，为编辑目标；取左侧正面全身，保留白发、龙角、翼、尾、白紫长裙和绳结饰物。输出为一张 1024×1536 的透明 PNG。生成式编辑可能与原参考存在细节差异。

项目最终路径：`F:\Codex\Projects\codex-opening-launcher\assets\dragon\dragon-front-v1.png`。

页面从同一张 PNG 通过 SVG 亮度与透明度滤镜派生线稿，再将彩色层以羽化遮罩从上向下逐阶段显现。两层共用尺寸和坐标。授权阶段只显出线稿；身份、接收请求、读取、核验、欢迎阶段依次将涂色位置推进到 20%、45%、72%、94%、108%，每次过渡 2.4 秒。角色本身不接收鼠标事件，支持减少动态效果的系统偏好。
