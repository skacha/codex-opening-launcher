# 原版移植与龙娘配色

## 原因

此前的 `aafd420` 使用 WPF 自行重绘了一个浅色终端，加入了自己的网格、侧边信息、五阶段正文和结尾确认按钮。虽然风格接近，但没有还原用户指定视频的实际画面、原版两步授权和转场。

本次改为移植对应原版网页运行时，并以用户补充的截图和龙娘三视图为准。原图不随仓库上传。

## 来源与证据

上游为 [6shenhonghong9/dsh-startup-screen](https://github.com/6shenhonghong9/dsh-startup-screen)，采用 `4a2cfe6`：

- `lib/splash.css` 的 `.dsu-brand`、`.dsu-center`、`.dsu-action`、`.dsu-reticle`、`.dsu-welcome` 定义原版品牌、版心、按钮、核验圆环和欢迎页。
- `lib/splash.js` 的 `run()`、`stepLoop()`、`waitAction()`、`finale()` 定义黑幕、洗白、五步授权与色散揭幕。
- 本项目保留原版 CSS 的几何参数与动画时长；脚本只新增宿主接入钩子。
- MIT 许可全文保存在 `assets/reference-boot/LICENSE`，详见根目录 `THIRD_PARTY_NOTICES.md`。

实际接入锚点：`ReferenceBootWindow.Initialize()` 将本地 `assets` 映射为 `https://codex-boot.local/`，加载 `reference-boot/index.html`；`Program.Main()` 在 `p.Mode == "eva"` 时使用该窗口。

## 最小修改

`codex-adapter.js` 替换左上品牌、黑幕品牌、页脚、欢迎框以及三个标识容器中的鲸鱼路径。显示用标识改为 Codex 终端符号，保留原版的勾线组装和落墨动画。

原版正文和版心保留：需要访问许可、身份资料确认、接收访问需求、开始读取权限、读取完毕与核验通过、欢迎页。画面恢复为截图中的中英双语，语音使用英文。没有继续添加上一版自行设计的侧栏、同步仪表或整排阶段导航。

行为变更点：恢复原版第一、第二步的真实授权交互，替代旧版末尾的 ENTER CODEX 确认页。用户确认后仍等待全部语音和原版揭幕完成，才激活应用。身份名称 JOYCE MOORE、编号 0087、等级 3 是原版演出资料，未执行真实账号认证。

## 龙娘配色

从用户三视图中对深色轮廓、淡紫衣饰阴影和银白区域分组取样，选取图中存在的代表色：

| 用途 | 颜色 | 来源区域 |
| --- | --- | --- |
| 原橙色强调、主墨色 | `#120C1B` | 深色轮廓 |
| 原蓝色光晕、紫色色散层 | `#C4BBDB` | 淡紫衣饰阴影 |
| 银白高光、另一层色散 | `#F9F5FA` | 银白衣发 |

原版中写死的橙色按钮呼吸光圈与蓝色光晕通过 `codex-palette.css` 覆盖。对应时钟、阶段条、声纹、准星小点、按钮光圈均使用轮廓黑，欢迎文字光晕和色散使用紫白。原版暖白底板、留白、线条和转场时长不变。

颜色值由 `palette.json` 提供；`ReferenceBootWindow.Initialize()` 读取后传给适配层，使用变量 `--dsu-accent`、`--dsu-glitch-a`、`--dsu-glitch-b` 控制。静态页面预览保留相同默认值。

## 稳健接入

- `ReferenceBootWindow` 继续调用原有 `DisplayHandoff.BeginIntro()`、`TryEnter()` 和 `Dispose()`，保留隐藏、同屏定位与失败恢复。
- 档案底板按参考截图约 1.58:1 比例等比缩放，设计窗口为 1264×800，字体和容器一起缩放；全屏保留边缘黑场。
- 正式、截图和录制分别使用独立的 F 盘 WebView 配置目录，避免同时运行时的配置冲突。
- 本地网页只访问映射的 `assets/`；拦截外部请求、外部导航和新窗口，不开放宿主对象。
- 初始化失败时取消启动并返回失败，不在未完成授权时自动打开应用。
- 使用已有 WebView2 Runtime，SDK 在构建时从微软官方源还原并校验 SHA-256，不修改 Codex 商店包。

六段英文 WAV 由 `build-reference-voice.ps1` 与既有 `VoiceProcessor.cs` 生成，台词与原版六阶段对应，末句为 Codex 欢迎语。保留此前的机械处理及基础电平额外提高 10%。BGM 仍为本项目合成，播报期间自动压低。未复制上游第三方人声与音效录音。

## 验证

- .NET Framework 构建成功。
- 七项原有播放回归通过：内置、原版主题、有声开关、图片、素材缺失、无效视频和正常视频；预览均未启动 Codex。
- 窗口预览实际完成鼠标“授予访问权限”与 Enter 身份确认；报告记录六句全部完成、两次确认、无应用启动。
- 屏幕 2 正式启动报告通过：`preview=false`、`sameMonitor=true`、`referenceConfirmations=2`、`voiceCues=6`、`voiceCompleted=6`。动画屏幕和应用目标均为 DISPLAY2，启动请求时间不早于动画完成时间。
- 正式序列含人工停留约 32.3 秒，渲染帧间隔 95 分位约 16.8 毫秒。未强制退出 Codex，因此验证的是已有应用窗口的接入，不代表完全冷启动实测。
- 最终配色视频录制约 24.7 秒的真实网页过程，捕获 1007 张源帧，导出 26 秒、60 帧编码 MP4。视频中的补帧率不代表每秒捕获了 60 张源帧。
- 全片 1560 帧和音轨解码成功；混音峰值约 -1.2 dBFS。
- 请求页、身份页、核验页和欢迎页已检查；最终请求页的强调元素为黑色，欢迎页为紫白光晕。

实时报告 `artifacts\reference-manual.report.json`、正式报告 `artifacts\reference-handoff.report.json` 及录制日志只保存在本机。

## 风险与回滚

新主题依赖电脑已有 WebView2 Runtime。首次构建需要下载官方 SDK，之后运行只使用本地文件。图片、视频与内置通用模式继续使用原实现。

`main` 保留 EVA 驾驶舱版，`aafd420` 保留上一版 WPF 浅色改编。本次构建前备份在 `F:\Codex\Projects\codex-opening-launcher\artifacts\before-reference-port`。可恢复旧 `CodexOpening.exe`，或在干净工作区切换对应提交并重新构建。任务栏入口、Codex 数据路径和账号配置未修改。
