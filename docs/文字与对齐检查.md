# 文字与对齐检查

## 原因与证据

`assets/reference-boot/splash.css` 的基础重置原先使用 `#dsh-startup-root * { margin:0;padding:0 }`，优先级高于 `.dsu-btn`、`.dsu-sub-en`、`.dsu-logo`、`.dsu-w2` 等规则，导致按钮内边距与标题、标识的上下间隔失效。隐藏光标仍参与标题的 flex 宽度计算，也会使可见中文偏离英文的中轴。

适配层的终端路径实际范围是 x=7…47、y=6…42，原 `viewBox="0 0 50 50"` 与实际图形中心不一致。原编号行的 `left:calc(50% + 190px);top:49%` 与英文副标题相交。以上均已在截图复查中确认。

## 字符核对

核对黑幕、品牌、授权、身份、请求、读取、核验、欢迎与页脚。Codex 品牌文字均为 `CODEX`，操作系统缩写为 `OS`，欢迎标题为 `WELCOME TO`，其中 O 是 U+004F；编号 `0087`、版本 `0.1.0` 中的零是 U+0030。没有发现这些文本把字母 O 实际写为数字 0；原字体小尺寸显示容易混淆。

品牌主要英文改用 Segoe UI，数字字段使用 Consolas 和等宽数字/斜线零特性，强化视觉区分。移除标识下 `C O D E X` 内的手工空格，统一通过字距排版。保留原演出身份 JOYCE MOORE/0087，不改变身份数据或授权流程。

## 修正

- 基础重置改为 `:where()`，恢复各组件的上下间距与按钮内边距。
- 光标绝对定位、不占标题宽度；无标识的阶段不保留隐藏标识的高度或外边距。
- 核验标题组与圆环同为 45% 的垂直中点，分隔线独立置于标题组下方，继续保留圆弧文字净空。
- 编号行移到左栏阶段条下方，避免与标题和角色面部重叠。
- 身份卡行内容垂直居中；按钮明确行高，欢迎框中文字使用 flex 居中。
- 三处终端标识统一使用 `viewBox="2 -1 50 50"`，按可见路径中心对齐。

## 验证与回滚

逐阶段导出黑幕及六阶段截图，并检查真实播放的逐字过渡。完整自动预览约 26.3 秒，六段英文语音全部完成，未启动 Codex，帧间隔 95 分位约 16.8 毫秒。报告为本机 `artifacts/text-alignment-playback.report.json`。

真实网页录制捕获 1249 张源帧，导出 26 秒有声预览，全片音视频解码通过。此次没有修改显示器接入或播放推进逻辑，也未重新执行正式应用接入。若回滚本次修改，恢复提交 `35d4e5e` 对应的网页文件即可，程序无需重新构建。
